# JEV Architecture — Interactive 3D Explanation Lab

A production-quality interactive 3D WebGL laboratory for explaining the complete **JEV Architecture**.

## Architectural Flow
```text
USER INTENT
     ↓
CONTEXT
     ↓
JEV DECISION CORE
     ↓
DECISION
     ↓
EXECUTION
     ↓
RESULT
```

## Architectural Layers

### Layer 04 — Intent and Interaction (Electric Blue: `#3B82F6`)
* User Intent
* Natural Language Request
* Goal Definition
* Context Input
* Decision Request

### Layer 03 — Context and Intelligence (Violet: `#8B5CF6`)
* Context Processing
* Relevant Information
* Decision Candidates
* Semantic Context
* Knowledge Retrieval
* Confidence Estimation

### Layer 02 — JEV Decision Core (Cyan: `#00D9FF`)
* Decision Engine
* Candidate Evaluation
* Scoring
* Policy and Constraints
* Confidence
* Decision Selection
* Structured Output

### Layer 01 — Execution and System Interface (Green: `#22C55E`)
* Tools
* APIs
* Applications
* External Services
* Automation
* Runtime
* Output

## Controls

### Hand Gestures
* **Pinch**: Rotate 3D Architecture
* **Open Palm**: Exploded View
* **Index Finger**: Explain Component / Advance Step
* **Swipe Left**: Previous Architectural Layer
* **Swipe Right**: Next Architectural Layer
* **Two-Finger**: System Detail View

### Keyboard Shortcuts
* `1` : Overview (Reset View)
* `2` : Layer 04 (Intent and Interaction)
* `3` : Layer 03 (Context and Intelligence)
* `4` : Layer 02 (JEV Decision Core)
* `5` : Layer 01 (Execution and System Interface)
* `Space` : Toggle Exploded View
* `E` : Toggle Step-by-Step Explanation Flow
* `R` : Reset Camera View
* `←` : Previous Layer
* `→` : Next Layer
* `Esc` : Close Explanation Panel
